# Rose code map

Rose's agent-facing tools are small JSON-stdin wrappers in
`rose_tools/calls/`. Their schemas are adjacent `.json` files, generated by
`rose_tools/chatbot/create_wrappers.py`. `rose_tools/chatbot/tool_dispatch.py`
routes calls to local programs and services. Start with the
[chatbot guide](../../rose_tools/chatbot/README.md).

| Need | Source |
| --- | --- |
| Camera capture and detection | [`rose_tools/camera/README.md`](../../rose_tools/camera/README.md) |
| Microphone and agent controls | `rose_tools/calls/rose_microphone.*`, `rose_tools/chatbot/` |
| Speech | [`rose_tools/voice/README.md`](../../rose_tools/voice/README.md) |
| Lighting | [`rose_tools/hue/README.md`](../../rose_tools/hue/README.md) |
| Disabled or removed hardware | `rose_tools/disabled_calls/` |

The local-wrapper pattern is useful for Lynx's future on-device AI. Rose's
camera and microphone hardware paths are separate from Lynx's.
