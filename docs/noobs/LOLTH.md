# Lolth code map

Lolth is the LAFVIN spiderbot. Start with [`lolth/README.md`](../../lolth/README.md).
Firmware is under `lolth/firmware/`, named motion programs under
`lolth/programs/`, and the local controller is `lolth/tools/lafvinctl.py`.
Actuator calls can move joints; use the explicit pose and stop semantics in
the README before calling them.
