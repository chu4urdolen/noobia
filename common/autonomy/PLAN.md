# Autonomy plan: making Lynx alive first, then every Noob

Gwyn plans, assigns, reviews, and takes the critical pieces. Banshee builds
the big features. Solo Dushich writes the services, Aigel, and the
documentation and atlas. Aria does only the final installs on Lynx, batched
into short **install sessions**, because her tokens are scarce.

Contract: [ARCHITECTURE.md](ARCHITECTURE.md). Forge project: `autonomy`
(and `lynx` for hardware). Task IDs below are used in forge notes.

## Rules for every task

- Work offline first, with tests that run in a fresh `git clone --no-local`.
  Write notes that claim only what the code and tests show.
- Anything that goes onto Lynx is an **install packet**. It lists:
  - files and hashes, modes;
  - install commands;
  - verification with expected output;
  - a local disable switch;
  - rollback;
  - and the attendance needed.

  Then: author → Gwyn review → Dushich second review → Aria install session.
- Build against `common/autonomy/test_contract.py`. If the contract seems
  wrong, raise it in forge; don't work around it.

## Phase 2: senses on Lynx (`lynx/senses/<sense>/`)

Each sense is a small supervised OpenRC service that emits through
`common/autonomy/sense.py`. Each is bounded, has fixtures and tests, and
ships as an install packet.

| ID | Sense | Events (examples) | Owner |
| --- | --- | --- | --- |
| S1 | `wifi` | `link.down` P1, `link.up` P1, `rssi.low` P3 | Dushich |
| S2 | `power` | `battery.low` P1, `charging.change` P2, `thermal.hot` P1 | Dushich |
| S3 | `touch` | `tap` P3, `hold` P2, from TOUCH_STATUS / runtime events | Dushich |
| S4 | `agent` | `job.done` P0, `job.failed` P2 (Lynx's own activity, `cause=self`) | Dushich |
| S5 | `mic` | `sound.loud` P3, then `speech.heard` P1 once H3 lands | Dushich |
| S6 | `camera` | `object.seen` P1 (label, conf), from frames sent to a detection service on Nexus | Dushich (Lynx side) and Banshee (Nexus detection service) |
| S7 | `nexus` | `unreachable` P1: Lynx can't reach Nexus | Dushich |
