# Rose code map

Rose's agent-facing tools are small JSON-stdin wrappers in
`rose/calls/`. Their schemas are adjacent `.json` files, generated by
`rose/chatbot/create_wrappers.py`. `rose/chatbot/tool_dispatch.py`
routes calls to local programs and services. Start with the
[chatbot guide](../../rose/chatbot/README.md).

| Need | Source |
| --- | --- |
| Camera capture and detection | [`rose/camera/README.md`](../../rose/camera/README.md) |
| Microphone and agent controls | `rose/calls/rose_microphone.*`, `rose/chatbot/` |
| Speech | [`rose/voice/README.md`](../../rose/voice/README.md) |
| Lighting | [`rose/hue/README.md`](../../rose/hue/README.md) |
| Disabled or removed hardware | `rose/disabled_calls/` |

The local-wrapper pattern is useful for Lynx's future on-device AI. Rose's
camera and microphone hardware paths are separate from Lynx's.
