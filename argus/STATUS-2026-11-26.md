## Gaps and cautions

- Council Codex bridge intentionally invokes an ephemeral, read-only Codex session. It is a speaking route, not an execution or historian task runtime. No Argus historian job service or authenticated MCP task route is installed yet.
- SSH accepts passwords. A working key route is confirmed, but physical recovery and all other legitimate login routes must be checked before changing SSH policy.
- The old `argus-backup.sh` uses `/home/todor` and `/mnt/nvme` and passes `rsync --delete`. Those paths do not match the active root-on-NVMe layout. Its timer and service are absent from live systemd. Do not enable it as written.
- `/mnt/nvme` is a regular directory on the NVMe root, not the active mount point. A separate historical copy of Argus's old repository lives there. Do not treat it as a verified off-device backup.
- The Pi's systemd boot timestamp predates its current uptime because time was corrected after boot. Use synchronized UTC time for new records and check boot ID when measuring persistence.
- This audit did not reboot the Pi, change its filesystem, test a restore, or verify the DHCP reservation at the router.

## Council address repair

The Pi's Council configuration still used the former `.5` Argus and `.6` Nexus addresses. On 2026-11-26, only the three contact hosts and four service address fields were updated to Argus `.105` and Nexus `.106`. Root owned originals are in `/var/backups/noobia-council-argus-addresses-1apmi3fq/` on Argus. Council, bridge, and web units were restarted and all returned active with successful results. `council.sh --busy` then returned `Argus IDLE`; before the edit it said `no arbiter reachable`.

The installed `council-config-check` rejected the pre-existing `os_user` line in the unchanged configuration. The first edit attempt restored its originals. The second edit was validated by parsing the contact JSON, checking all four address fields, restarting the live services, and issuing the authenticated `--busy` call. The checker version should be reconciled before relying on it for future Council changes.
